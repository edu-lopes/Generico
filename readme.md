# 🧪 Lab de Ideias: Úteis, Inúteis e Afins

Bem-vindo ao meu "parquinho" de código! Este repositório serve como um **sandbox** para testar lógica, novas tecnologias, ideias brilhantes e, principalmente, aquelas ideias que não servem para absolutamente nada, mas foram divertidas de programar.

---

## 🎯 O Objetivo
A ideia aqui não é ter um projeto finalizado com 100% de cobertura de testes ou pronto para produção. O objetivo é a **experimentação pura**. Se eu vi um conceito novo ou tive uma ideia aleatória às 2 da manhã, o código vem parar aqui.

---

## 📂 O que você vai encontrar por aqui?

A estrutura é dividida basicamente pelo nível de "utilidade" do código:

### 🚀 Coisas Úteis (Utility Belt)
Scripts e funções que realmente resolvem problemas ou facilitam a vida.
* **Automações:** Scripts em Python/Bash para organizar arquivos ou minerar dados.
* **Snippets:** Padrões de design ou funções auxiliares reaproveitáveis.
* **Boilerplates:** Estruturas iniciais para projetos rápidos.

### 🤡 Coisas Inúteis (Fun & Chaos)
Projetos que desafiam a lógica da produtividade.
* **Geradores de Lero-Lero:** Criadores de frases motivacionais duvidosas.
* **Calculadoras de Probabilidades Improváveis:** *"Qual a chance de chover marshmallows hoje?"*
* **CSS Art:** Experimentos visuais que não servem para um site real, mas ficam bonitos.

### 🧪 Afins (Deep Dives)
Estudos de caso e testes de bibliotecas.
* Testes de performance entre linguagens.
* Explorações de APIs públicas estranhas.

## 🧬 Como rodar os experimentos?

Cada pasta dentro deste repositório contém seu próprio arquivo `README.md` (ou pelo menos deveria) explicando como rodar aquele experimento específico. No geral:

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/edu-lopes/Generico.git
    ```
2.  **Explore as pastas:** Navegue pelos diretórios e siga as instruções locais.
